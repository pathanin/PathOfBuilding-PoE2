## Where do I add X?
- New calculation → the relevant `src/Modules/Calc*.lua`; register any new displayed stat in `src/Modules/BuildDisplayStats.lua` and give it a row in `src/Modules/CalcSections.lua`
- New modifier text pattern → `src/Modules/ModParser.lua`, then regenerate `src/Data/ModCache.lua`
- New Configuration tab option → `src/Modules/ConfigOptions.lua`
- New UI control or tab → `src/Classes/`, one file per class, instantiated via `new("ClassName", ...)`
- New unique item → the matching equipment-class file in `src/Data/Uniques/` (or `src/Data/Uniques/Special/` for generated/special cases)
- New system test → a Test&lt;Topic&gt;_spec.lua file in `spec/System/`
- New game data pulled from the GGPK → a script in `src/Export/Scripts/`, output landing in `src/Data/`
- New passive tree version → a new version directory under `src/TreeData/`, and add the version to `src/GameVersions.lua`
